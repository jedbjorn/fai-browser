FAI Browser is ready

This Firefox window uses the separate FAI profile your coding agent works in.

Setup checks

  • ?Open this page with fai-browser launch to see the checks.

The add-on pairs with the FAI service by itself. Click the FAI Browser button on the toolbar: it should say Connected to the FAI service.

How you stay in charge

  1. Your agent asks for a site and says why. Its page opens in a new window with a small prompt.
  2. Click the FAI Browser button on that page to approve. Nothing happens until you do, and the agent never chooses a tab by itself.
  3. While it works, the tab sits in a FAI tab group. Pause or stop from the button at any time.
  4. Risky steps (a purchase, a delete, revealing a key) also need Approve once: single-use, for that one control.

Levels

You seeThe agent may
Readfollow links on the site, scroll, wait
Usealso click buttons, pick options, fill values you supplied, search, filter, sort
Actalso save, send, submit, delete, accept cookies
Test siteeverything including sign-in and checkout, only on test sites you listed

The agent asks for the lowest level that works; you can lower it when you approve.

Secrets stay hidden

API keys, tokens, passwords and card numbers on a page reach the agent as placeholders such as [secret:3 …], and are blacked out in screenshots before they leave the browser. With your approval the agent can paste or copy one without ever seeing it.

This profile

It is separate from your everyday Firefox: other bookmarks, history and sign-ins. Sign in here only to accounts the agent may use. Passwords are not saved and card autofill is off in this profile; HTTPS-Only is on. Firefox updates itself from Mozilla as usual.
