## Labeled performance charts

`benchmark-text-data.json` and `benchmark-visual-data.json` feed the two same-origin task charts.
`benchmark-text.svg` and `benchmark-visual.svg` are standalone versions embedded in the README.
All four are generated by `npm run site:benchmark-data` from checked-in bench results
(`scripts/site-benchmark-data.mjs`); do not hand-edit them. Each chart labels Playwright MCP,
FAI Agent direct and FAI Jev autopilot directly on its bars, with no A/B legend or ratio-only view. The Jev bars are
historical: the experimental autopilot was removed after 0.6.2.

`site/index.html` carries the measured SVG and text tables inside `<!-- figure:text -->` and
`<!-- figure:visual -->` markers, so results remain available without JavaScript or if a fetch
fails. The generator splices those static snapshots; run it after any benchmark refresh and
commit the JSON, SVG and HTML together. Only complete, validated results may be published.

Both JSON files use `schemaVersion: 3` with `kind: "grouped"` and `status: "complete"`. Each has
exactly four `metrics` — `passes`, `wall`, `tokens`, `cost` — with points named `playwright`,
`agent` and `jev`. Each point has a finite, non-negative `value` and a display string. Every
metric shares a zero baseline and scale across its three bars. `run` records the model, task
count, repeats, measurement time and repository sources.

Wall time is host spawn to exit with model latency dominant. Raw host tokens are full model
usage per vendor tokenizer; visual-task counts include screenshot image tokens. Jev provider
tokens are additional and excluded from the host-token and host-cost bars. Cost is
list/API-equivalent pricing, not a subscription invoice. The two safety scenarios (purchase
approval, fake-secret login) are excluded from every performance figure.

The separate twelve-page opening-token evidence is hard-coded from the release 0.3.1
`bench/tokens/results-real-0.3.1` corpus: medians of 1,147 versus 11,786.5, a 90.27% reduction
displayed as 90.3%. It measures output size, not task success. The demo retains its historical
release 0.3.0 chart with the earlier 1,130 median.
