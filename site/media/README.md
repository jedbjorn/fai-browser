## `benchmark-data.json` and `jev-matrix-data.json`

The two task charts read these same-origin JSON files: Agent direct (the default driver) and the
experimental Jev autopilot. Both are generated by `npm run site:benchmark-data` from checked-in
bench results (`scripts/site-benchmark-data.mjs`); do not hand-edit them. `site/index.html`
carries the measured SVG and text tables inside `<!-- figure:agentdirect -->` and
`<!-- figure:jev -->` markers, so results remain available without JavaScript or if a fetch
fails. The generator splices those static snapshots; run it after any benchmark refresh and
commit both together. Only complete, validated results may be published.

Both files use `schemaVersion: 2` with a shared shape:

- `kind`: `"paired"` (Agent direct) or `"ratio"` (Jev).
- `status`: `"complete"`; anything else leaves the static snapshot in place.
- `label`: methodology label shown below the chart.
- `run`: `model`, `driver`, `protocol`, `taskCount`, `repeats`, `measuredAt`, `source`
  (repository path of the bench output the data came from).
- `series`: `a` (Playwright MCP, with version) and `b` (the FAI driver, with version).

`kind: "paired"` (Agent direct) has exactly four `metrics` — `passes`, `wall`, `tokens`, `cost` —
each with `label`, `unit`, and two points `a`/`b`. Each point has a finite, non-negative `value`
and an optional string `display`. Bars share a zero baseline and scale. `wall` is per-task wall
time in seconds, `tokens` is raw model tokens per task (full vendor usage, text only on these
tasks), `cost` is USD per task priced from `bench/prices.json`. Figures are suites of per-task
medians over repeats. A `ratios` block carries A-over-B multiples for reference.

`kind: "ratio"` (Jev) has three `metrics` — `wall`, `tokens`, `cost` — each with a `hosts` array
of `{name, value, display}` where `value` is Playwright MCP ÷ FAI for that host (above 1 favours
FAI), plus `min`, `max` and `median` across hosts. A `hosts` array with per-host pass counts
feeds the text table.

Wall time is host spawn to exit with model latency dominant. Raw model tokens are full host
usage per vendor tokenizer; visual-task counts include screenshot image tokens. Jev provider
tokens are excluded from chart ratios and reported separately in the README. Cost is
list/API-equivalent pricing, not a subscription invoice. The two safety scenarios (purchase
approval, fake-secret login) are excluded from every performance figure.

Do not put Jev autopilot numbers in the Agent-direct chart or vice versa; the drivers are measured
and labelled separately. The separate twelve-page opening-token evidence is hard-coded from the
fresh release 0.3.1 `bench/tokens/results-real-0.3.1` corpus: medians of 1,147 versus 11,786.5, a
90.27% reduction displayed as 90.3%. It measures output size, not task success. The demo retains its
historical release 0.3.0 chart with the earlier 1,130 median.
