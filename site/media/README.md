## Performance figures

The public trial figures in `site/index.html` (between the `<!-- public-pilots -->` and `<!-- gmail-case -->`
markers) are generated by `npm run site:benchmark-data` (`scripts/site-benchmark-data.mjs`) from the sanitized
measurements in `evidence/`; do not hand-edit them. The fixture task comparison (Playwright MCP versus FAI Agent
direct) is the README table, sourced from the checked-in bench summaries. Wall time is host spawn to exit with model
latency dominant; cost is list/API-equivalent pricing, not a subscription invoice. The two safety scenarios
(purchase approval, fake-secret login) are excluded from every performance figure.

The separate twelve-page opening-token evidence is hard-coded from the release 0.3.1
`bench/tokens/results-real-0.3.1` corpus: medians of 1,147 versus 11,786.5, a 90.27% reduction
displayed as 90.3%. It measures output size, not task success. The demo retains its historical
release 0.3.0 chart with the earlier 1,130 median.
