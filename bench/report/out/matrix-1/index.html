Methodology

  • 8 read-only browser tasks on a local deterministic fixture site; each host runs every task under A (Playwright MCP as its only browser tool) and B (FAI Browser MCP). Cells are medians of up to 3 repeats; totals sum the per-task medians.
  • Wall time runs from spawning the host to its exit, including MCP start-up and every model turn. Model requests are host model round trips. Pass is a strict normalized answer match.
  • Priced tokens weight the token split relative to one uncached input token: uncached × 1, cached × 0.1, cache write × 1.25, output × 5 (assumed weights, not a price list). Cost applies bench/prices.json (2026-10-04, USD per million tokens) to the same split; Claude rows are list prices, Codex rows are API-equivalent, since a ChatGPT plan bills quota rather than dollars.
  • Runs are deduplicated by task, condition, host and repeat; when sets overlap the newer set wins (24 runs replaced, 144 kept). Sets: 2026-10-04-oversight-2 (24 runs), 2026-10-04-matrix-1 (72 runs), 2026-10-04-matrix-1-baseline (72 runs). Corpus: qa-2026-10-04T09-43-38-315Z-machinery.
  • Generated 2026-10-04 by bench/report.mjs. Headless Chromium for both conditions; the harness approves FAI tab requests in about 0.4 s.
